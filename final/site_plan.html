Individual Project Site Plan

Site Name

Cheyenne YSA Activities. This is a basic title to get across what the web page will be about. I will be going over some of the YSA activities. This includes previous activities and upcoming activities. The title gets across that those activities is what this web page will be about.

Site Purpose

This website is to categorize the different activities that the Cheyenne YSA has. This includes old activities and how they went. New upcoming activities, a way to send in suggestions for activities. Also there should be included a way to contact leadership. This is so leadership can tell how well received an activity was, and others can see what the YSA has been up to and how they can join.

Scenarios

  • "How can I join in on these activities?"
  • "I have an amazing activity idea, where can I share this idea?"

Color Scheme

  • Primary Blue (#140a70): Dark Blue that will be used for main headings, links, and important informational text. this calm color will help guide the eye to important information.
  • Accent Yellow (#d8ca06): A bright yellow that will be used for call-to-action buttons, highlights, and key interactive elements. It is warm, happy, and draws user attention.
  • Dark Text (#14213d): A simple dark grey color used for all paragraphs and body content to ensure high readability and contrast.
  • Light Background (#edf2f4): A simple color white used for the main body background to provide a soft, clean, and non-distracting canvas for the content.

Typography

The primary font for the entire website will be 'Roboto', served from Google Fonts.

  • Headings (h1, h2, h3): Will use Roboto with a bold weight (800) to draw the eye in, and create a bigger heading.
  • Body Text (paragraphs, lists): Will use Roboto with a regular weight (400) to cleanly get information across
